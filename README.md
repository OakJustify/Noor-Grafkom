# NOOR

Game 2D side-scroller naratif tentang pengalaman Alzheimer.

## Peringatan Konten
Tema berat: kehilangan, kegelapan, kematian simbolik. Rekomendasi 13+.

## Instalasi
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Menjalankan
```bash
python main.py
```

## Kontrol
A/D gerak, Space lompat, E interaksi, F flare, C tutup lentera, Esc jeda.
