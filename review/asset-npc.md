### Sentry Implementation
**File:** `challenges.py:215-240 EnemySpec` + `procedural.py:857-881 _update_challenges()`

```python
# Patrol behavior
state.x += state.direction * speed * dt
if state.x < enemy.patrol_left:
    state.x = enemy.patrol_left
    state.direction = 1
elif state.x > enemy.patrol_right:
    state.x = enemy.patrol_right
    state.direction = -1

# Lantern interaction
lit = self.lantern_on and self.lantern_energy > 0
if lit and p.get_distance((state.x, enemy.y)) < self.config.enemy_light_radius:  # 132px
    state.stun = max(state.stun, self.config.enemy_stun_time)  # 0.75s
    state.direction = 1 if state.x >= p.x else -1  # Retreat from lantern

# Damage
if state.stun <= 0 and rects_overlap(body, enemy_rect):
    self.take_damage(enemy.damage, source_x=state.x, ...)
```

**Properties:**
- Patrol range: `patrol_left` to `patrol_right` (platform-width dependent)
- Speed: `42 + 5 * max(0, difficulty - 1)` → 42-87 px/s at difficulty 1-10
- Damage: 1 (same as saw)
- Stun: 0.75s when lantern in range (132px)
- Retreat: Runs away from player when stunned

**Rendering:** `forest.py:1122-1134` — ellipse + eyes (color changes when stunned)
